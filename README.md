## Snake Game 2.0

Link: https://a4-ella-brown.onrender.com

Include a very brief summary of your project here and what you changed / added to assignment #3. Briefly (3–4 sentences) answer the following question: did the new technology improve or hinder the development experience?

This project is a simple game of snake. Players can play the game, add/edit/remove their scores, and see the highest scores on the leaderboard.
Overall, the new technology improved the development experience. Svelte was not significantly difficult to learn and allowed the same actions to be written with less complicated code. Svelte is also more compact in terms of compile/run time, which made the code easier to deploy and test.
